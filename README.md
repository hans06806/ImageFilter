# 🧠 AI vs Human Image Classification with ResNet-50 (MATLAB)

This project applies transfer learning with ResNet-50 to classify whether an image was generated by AI or created by a human. It fine-tunes a pre-trained deep learning model using a balanced dataset and evaluates performance on mixed, unlabeled image data.

---

## 📌 Overview

- ✅ Model: ResNet-50 (pre-trained on ImageNet)
- 🎯 Task: Binary classification — Human vs AI-generated images
- 🛠️ Tools: MATLAB Deep Learning Toolbox
- 📊 Output: Predicted class labels with optional visual preview

---

## 🧪 Dataset

- 1,000 AI-generated images from [DiffusionDB](https://poloclub.github.io/diffusiondb/)
- 1,000 human-generated images from [FFHQ](https://github.com/NVlabs/ffhq-dataset)
- 2,000 mixed unlabeled test images for inference
- Preprocessing includes resizing to 224×224 and data augmentation (flipping, rotation, shifting)

> Note: Due to file size, the datasets are not included. Sample test images can be added to `MixedTest/`.

---

## 🧰 Scripts

| Script | Purpose |
|--------|---------|
| `load_dataset.m` | Loads and augments the training dataset |
| `modify_resnet50.m` | Replaces ResNet-50's output layer with binary classifier |
| `train_resnet50.m` | Trains the modified network using training options |
| `predict_mixed_images.m` | Classifies unlabeled images in the `MixedTest/` folder |

---

## 🔍 Demo

Once trained, the model can classify a folder of unlabeled images.  
It shows a bar chart summary of predictions and a preview of top predictions.

---

**Example Output:**
